## 1. 기획 & 디자인 가드레일 확정

- **목적 정렬:** 사업 탐방 10분 발표의 마지막 1~2분 동안 실제 라이브 사이트를 띄워 3인 팀의 실행력과 차기 개인 프로젝트 라인업을 1초 스캔 가능한 밀도로 보여주는 쇼케이스 설계.
- **AI 웹 템플릿 클리셰 배제 원칙:**
  - 중앙 정렬 SaaS 히어로, 반짝이(`✨`) 알약 배지, 대칭 3단 아이콘 카드, 보라/파랑 그라데이션, Glassmorphism(반투명 블러), 흐릿한 드롭 섀도우, 기본 이모지 남발 전면 금지.
  - 추상적 미사여구 배제 및 텍스트 압축 규칙 적용(섹션 헤드라인 15자 이내, 서브 카피 1줄 35자 이내, 카드 설명 2줄 이내 팩트·수치 중심).
- **확장성 설계:**
  - 차기 개인 프로젝트 3종은 개발 초반 단계이므로 단독 상세 페이지(`/projects/[slug]`) 라우트를 미리 만들지 않고 전부 프리뷰 모달로 표시하되, 데이터 모델에 `slug`와 `hasDetailPage: boolean` 플래그 및 클릭 분기 로직을 선반영해 추후 고도화 시 즉시 승격 가능하도록 설계.

## 2. 전역 디자인 시스템 & 정적 데이터 계층 구축

### 2-1. 아케이드/인디 패키지 디자인 시스템 (`src/app/globals.css`, `src/app/layout.tsx`)
- **컬러 팔레트:**
  - 배경(Canvas): `#FAF7F2` (웜 오프화이트) / 카드 표면(Surface): `#FFFFFF` (순백)
  - 잉크 & 보더(Ink): `#18181B` (짙은 잉크 차콜) / 보조 텍스트: `#52525B`
  - 포인트 컬러(절제 사용): `#FF5A1F` (비비드 오렌지), `#FACC15` (머스타드 옐로우)
- **하드 보더 & 오프셋 섀도우 유틸리티:**
  - `2px solid #18181B` 실선 보더 + `4px 4px 0px #18181B` 각진 하드 섀도우(`.arcade-card`, `.arcade-btn`, `.arcade-row`) 및 클릭 시 눌림 오프셋 인터랙션 구현, 모서리는 `rounded-lg` 이하로 절제.
- **타이포그래피:**
  - 한글 가독성을 위해 Pretendard Variable Dynamic Subset 기본 적용 + 수치/인덱스(`01`~`03`, `16:9`)에 `font-mono` 및 `tabular-nums` 적용.

### 2-2. 정적 데이터 집중 관리 (`src/data/`)
- 하드코딩을 배제하고 추후 확정 카피·수치·링크 교체만으로 사이트 전체가 갱신되도록 TypeScript 타입과 함께 분리:
  - `src/data/types.ts`: 전역 데이터 인터페이스 정의
  - `src/data/site.ts`: 스튜디오명, 3개 섹션 네비게이션, 푸터, `steamUrl` (비어 있으면 `STEAM · COMING SOON`, URL 입력 시 라이브 링크 버튼으로 자동 전환)
  - `src/data/hero.ts`: 팀 프로젝트 타이틀(가제)·1줄 카피·2×2 핵심 수치·미니게임 클립/스크린샷 3종 슬롯 (`public/media/` 경로 매핑)
  - `src/data/behind.ts`: 기획 피벗 3단계(`BEFORE → PIVOT → NOW`), AI·MCP 파이프라인 제작 효율, 실제 기술 해결 사례 2건(`문제 → 해결`)
  - `src/data/upcoming.ts`: 차기 개인 프로젝트 3종(`SCRAP COURIER`, `DECK BUNKER`, `SIGNAL ZERO` 가데이터)

## 3. 핵심 섹션 & 인터랙션 구현 (`b9e6b73`)

### 3-1. 컴팩트 고정 헤더 & Steam CTA (`src/components/Header.tsx`, `src/components/SteamCtaButton.tsx`)
- `h-14` 고정 헤더(블러 없는 솔리드 `#FAF7F2` + 하단 `2px` 실선)에 스튜디오 마크, 3개 섹션 앵커 점프(`01 메인 프로젝트` / `02 개발 비하인드` / `03 차기 라인업`), Steam 상태 배지 배치.

### 3-2. 메인 히어로 — 12컬럼 5:7 비대칭 분할 (`src/components/HeroSection.tsx`)
- 1080p 발표 화면에서 스크롤 없이 히어로 전체가 한눈에 들어오도록 상하 패딩을 컴팩트하게 조정.
- **좌측(5컬럼):** 팀 프로젝트 타이틀 + `가제` 태그, 1줄 카피, 2×2 핵심 수치 스펙 그리드, Steam CTA 및 비하인드 점프 버튼.
- **우측(7컬럼):** `public/media/` 파일 교체만으로 바로 `<video>`/`<img>`가 렌더링되는 16:9 플레이스홀더 프레임(`public/media/README.md` 가이드 포함) + 하단 미니게임 클립 3종 즉시 전환 탭 바.

### 3-3. 개발 비하인드 & 파이프라인 — 상/하 2단 리듬 (`src/components/BehindSection.tsx`)
- **상단 풀폭 피벗 바:** `BEFORE(턴제 전략)` → `PIVOT(원초적 물리 재미)` → `NOW(액티브 래그돌 파티 게임)` 3단 가로 스트립을 컴팩트하게 배치해 하단 2분할이 한 화면에 함께 보이도록 구성.
- **하단 비대칭 2분할:** 좌측(5컬럼) AI·MCP 파이프라인 제작 효율(도구 태그 + 핵심 수치 3건), 우측(7컬럼) 실제 기술 해결 사례 2건(액티브 래그돌 팔 클리핑 해결, Unity NGO 멀티플레이 물리 동기화) `문제 → 해결` 2줄 포맷.

### 3-4. 차기 프로젝트 3종 인덱스 리스트 & 프리뷰 모달 (`src/components/UpcomingSection.tsx`, `src/components/ProjectPreviewModal.tsx`)
- 3단 대칭 카드 클리셰와 불필요한 빈 이미지 박스를 배제하고, `번호(01~03) + 프로젝트명 + 장르/단계 배지(Prototype / Concept) + 1줄 훅 + 우측 화살표` 구조의 아케이드 카탈로그 리스트로 구현.
- 행 전체 호버 시 미세 오프셋 및 포인트 컬러 반응, 클릭 시 `hasDetailPage` 플래그 분기 후 콤팩트 프리뷰 모달 오픈(장르·기술 스택 태그, 1줄 로그라인, 기획 핵심 포인트 3줄, 개발 단계 표시, `ESC` 및 외부 클릭 닫기 지원).
