## 1. 1페이지 (`Game`) 영상 전환 & `Highlights` 완성

- **영상 자동 전환 로직 개선 (`src/components/home/SceneCarousel.tsx`):**
  - 기존 6초 타이머가 풀스크린 영역의 `onMouseEnter` 일시정지 때문에 마우스 커서가 화면에 올라가 있으면 멈추던 문제를 해결.
  - 마우스 호버 일시정지를 제거하고 **각 영상 1회 재생 완료 시(`onEnded`) 다음 씬(`01 → 02 → 03 → 01`)을 `0초`부터 자연스럽게 크로스페이드 재생**하도록 전환 (`IntersectionObserver` 스크롤 이탈 시 자동 일시정지 유지).
  - 영상 좌하단에 `PROJECT 01` 맥락 라벨 추가.
- **`Highlights` 섹션 폴리싱 (`src/components/home/GameFeaturesSection.tsx`, `src/components/SteamCtaButton.tsx`):**
  - 섹션 제목을 `Features` → **`Highlights`**로 교체하고, 넘버링(`01~03`)을 **`물리` · `액션` · `모드`** 2글자 한글 태그(`shortLabel`)로 교체해 모바일·데스크톱 스캔력 향상.
  - 옐로우 채움 과다를 줄이기 위해 태그와 `STEAM · COMING SOON` 버튼을 **옐로우 아웃라인**으로 통일.
  - Before/After 비교 검수를 반영해 **선택된 박스는 좌측 `4px` 옐로우 강조선 + `#1E2128`**, **비선택 박스는 투명 테두리 + 옅은 배경(`opacity-65`)**으로 명확한 대비 확보.
  - 스크린샷 전환은 미세 줌을 제거한 순수 `500ms` 크로스페이드로 정리하고 우하단 `01/03` 오버레이 제거.

## 2. 모바일 반응형 UX 보강 (데스크톱 변경 0px)

- **1페이지 영상 (`SceneCarousel.tsx`):** 모바일 높이 컴팩트 조정(`56vh`, `max-h-[520px]`), 타이틀·씬 바 상하 분리 및 **좌/우 터치 스와이프** 전환 추가.
- **1페이지 `Highlights` (`GameFeaturesSection.tsx`):** 모바일에서 3개 설명을 세로로 길게 펼치지 않고 **`16:9 스크린샷(스와이프)` → `물리·액션·모드` 3분할 탭 → `선택된 1개 설명` → `Steam 버튼`** 한 화면 완결형으로 구성해 스크롤 번거로움 제거.
- **2페이지 조작키 (`BasicGuideSection.tsx`):** 모바일 2열 그리드 압축 + 커스터마이징·스테이지 선택 프리뷰 상단 배치.
- **4페이지 연락처 (`ContactSection.tsx`):** 좁은 화면에서 이메일·COPY 버튼 풀폭 정렬.

## 3. 스튜디오 정체성 확립, 언어 위계 통일 & 2~4페이지 마감

- **명확한 언어 위계 & 불필요 넘버링 제거:**
  - **헤더 4탭 (`Game · Guide · Devlog · Studio`, 넘버링 제거) + 노란 세로선 대제목 (`Highlights`, `How to Play`, `Stages & Rules`, `Devlog`, `Team`, `Upcoming`, `Contact`)**만 영문으로 통일하고, 내부 소제목·태그·설명은 전부 한글로 통일(고유명사·`BEFORE/PIVOT/NOW`·`Works` 제외).
  - 2페이지 탭 넘버링(`01~03`), 3페이지 중복 `주제 피벗` 바·영문 툴 태그 4종·`NOTE 01·02` 넘버링, 4페이지 `Upcoming` 넘버링 제거.
- **전 페이지 플랫 서피스 디자인 통일 (`bg-[#1A1D24]` + `border-white/[0.08]`, 그림자 0):**
  - 2·3페이지의 2단·3단 가로 구역 구분감을 살리면서도 1·4페이지의 담백한 톤을 해치지 않도록 그림자 없는 플랫 서피스로 전 페이지 통일.
- **4페이지 `Studio` 고도화 (`src/components/team/`, `src/components/BrandIcons.tsx`):**
  - `Team`: 팀원 3인 개별 플랫 박스 + 단색 `GitHub` SVG 아이콘 + **`Works`** 모달 버튼(`h-8` 높이 통일, 슬레이트 서피스 + 호버 옐로우).
  - `MemberDetailModal.tsx`: 포트폴리오 링크 대신 팀원별 간단 소개·`FLIP & FLOP` 참여 작업 내역·사용 툴을 보여주는 깔끔한 상세 모달 구현(중복 넘버링·하단 푸터 제거).
  - `Upcoming`: 차기작 3종 단일 플랫 리스트 + 진행 단계별 사각 도트(`프로토타입` 옐로우 / `기획` 그레이).
  - `Contact`: `Contact` 대제목을 박스 바깥 상단으로 통일 + 옐로우 아웃라인 이메일 CTA + 단색 `GitHub`·`YouTube`·`X` SVG 아이콘 적용(불필요한 대각선 화살표 제거).
