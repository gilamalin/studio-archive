## 3. 1페이지 영상 쇼케이스 & UX 최적화

- **실제 미디어 연결 (`public/media/`):**
  - GitHub에 업로드된 플레이 영상 3종(`scene-01.mp4`, `scene-02.mp4`, `scene-03.mp4`)과 스크린샷 3종(`feature-01-physics.jpg`, `feature-02-grab.jpg`, `feature-03-party.jpg`) 연결.
- **경계 없는 풀블리드 히어로 (`src/components/home/SceneCarousel.tsx`):**
  - 밝은 3D 카툰 영상과 어두운 배경 간의 사각 경계 이질감을 해소하기 위해 화면 풀폭 영상 + 하단 `#14161B` 그라데이션 융합 적용.
  - 영상 상단 크롭 방지를 위해 `object-top` 적용, 8px 도트 대신 클릭 영역이 넉넉한 우하단 `01 · 02 · 03` 미니 씬 바 버튼으로 개선.
  - `IntersectionObserver`로 하단 `재미 요소` 섹션 진입 시 영상 자동 일시정지 + 밝기 `brightness-[0.55]` 톤다운 처리.
- **부드러운 2화면 전환 (`src/components/home/HomeSnapController.tsx`):**
  - 브라우저 기본 `scroll-snap`의 급격한 튕김 대신 `requestAnimationFrame` 기반 `780ms` `easeInOutQuart` 스크롤 전환 구현.
  - Windows `prefers-reduced-motion` 환경 및 라인 모드 마우스 휠(`deltaMode === 1`) 대응 보완.
- **전환 성능 & 하이드레이션 수정:**
  - 브라우저 확장 프로그램이 `<body>`에 속성을 주입해 발생하던 개발 경고에 `suppressHydrationWarning` 적용 (`src/app/layout.tsx`).
  - 헤더 슬라이딩 언더라인 (`src/components/Header.tsx`)에 클릭 즉시 선반영(Optimistic UI) + GPU 가속(`will-change-transform`)을 적용하고, 1페이지 복귀 시 비활성 영상 2개를 `450ms` 지연 마운트(`preload="none"`)해 60fps 전환 유지.
